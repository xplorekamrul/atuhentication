# Mandatory Alignment & Confirmation Before Code Changes

> **CRITICAL RULE**: Never make blind, unilateral, or unprompted code modifications without prior discussion and explicit confirmation from the user.

## Workflow Rules

1. **Investigate & Diagnose**:
   - Inspect files, databases, or runtime behaviors to understand the issue thoroughly.

2. **Discuss & Explain First**:
   - Communicate the findings, root causes, and context clearly to the user.
   - Explain what is happening and why.

3. **Present the Proposal**:
   - Outline the proposed plan of action.
   - List the specific files that need to be created or modified, and the rationale for each change.

4. **Wait for User Confirmation**:
   - Do NOT edit or write code until the user has confirmed the approach or provided feedback.
